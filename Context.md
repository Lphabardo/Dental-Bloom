# **1\. ОБЩАЯ КОНЦЕПЦИЯ ПРОЕКТА**

Dental Bloom — персональное образовательное приложение для ученицы первого года Ausbildung по профессии Zahnmedizinische Fachangestellte (ZFA) в Германии.

Главная задача приложения — помочь ученице постепенно освоить школьную программу ZFA, улучшить профессиональный немецкий и начать изучать английский практически с нуля.

Приложение должно превратить самостоятельное обучение из сложной и непонятной задачи в простой ежедневный процесс.

Вместо того чтобы открывать учебник и не понимать, с чего начать, ученица открывает Dental Bloom и сразу видит:

* что ей сегодня нужно изучить;  
* сколько времени это займёт;  
* что она узнает;  
* какие слова нужно запомнить;  
* какие задания нужно выполнить;  
* что следует повторить.

Основная идея:

**Little steps. Bright future.**

Небольшие ежедневные занятия должны постепенно приводить к реальному результату.

Dental Bloom — это не просто словарь, не обычный планировщик и не копия Duolingo.

Это персональный учебный помощник, который объединяет:

1. Профессиональные знания ZFA.  
2. Немецкий язык для учёбы и стоматологической практики.  
3. Английский язык с самого начального уровня.  
4. Повторение и закрепление знаний.  
5. Короткие интерактивные задания.  
6. Персональный учебный маршрут.  
7. Отслеживание прогресса.

Приложение должно быть красивым, спокойным, понятным и мотивирующим.

Важно: Dental Bloom не заменяет Berufsschule, преподавателей или профессиональное обучение в стоматологической практике. Оно помогает лучше понимать и закреплять материал.

# **2\. ДЛЯ КОГО СОЗДАЁТСЯ ПРИЛОЖЕНИЕ**

## **2.1. Информация об ученице**

Приложение изначально создаётся для конкретной ученицы.

Известная информация:

* Она проходит первый год Ausbildung ZFA.  
* Учится в Berufsschule в Rosenheim, Bayern, Deutschland.  
* Посещает Berufsschule примерно два раза в неделю.  
* В остальные дни проходит практику в стоматологической клинике.  
* Сейчас изучает темы, связанные с лечением кариеса (LF 4).  
* Немецкий язык — приблизительно A2.  
* Понимает простые немецкие фразы, но испытывает трудности со сложными учебными текстами.  
* Английский язык — практически с нуля.  
* Есть трудности даже с правильным чтением английских слов.  
* Основной язык объяснений — русский.  
* Немецкий должен постепенно становиться вторым языком объяснений.

## **2.2. Учебные трудности**

Основные проблемы:

1. Не всегда понимает, что именно объясняет преподаватель.  
2. Сложно самостоятельно разбираться в учебных материалах на немецком.  
3. Не знает, с чего начинать подготовку.  
4. Не имеет устойчивой привычки регулярно учиться.  
5. Испытывает трудности с профессиональной лексикой.  
6. Английский практически не освоен.  
7. Может чувствовать себя перегруженной из\-за количества учебной информации.

Приложение должно учитывать эти трудности.

Нельзя предполагать, что ученица сможет самостоятельно прочитать сложный немецкий текст и понять его.

Материал необходимо объяснять постепенно, небольшими частями.

## **2.3. Неизвестная информация**

Пока неизвестно:

* полное расписание Berufsschule;  
* точная расшифровка всех сокращений расписания;  
* полный список школьных предметов;  
* оценки по каждому предмету;  
* точные учебники;  
* полный список тем, которые они уже прошли;  
* даты следующих контрольных работ.

Пользователь сообщил, что сокращение BA означает Behandlung Assistent / урок, связанный с ассистированием при лечении.

Необходимо учитывать:

**Не выдумывать расшифровки школьных сокращений.**

Если информация неизвестна, помечать её как неизвестную.

Не делать предположений о расписании и школьной программе без подтверждения.

# **3\. ПРОБЛЕМЫ, КОТОРЫЕ ДОЛЖНО РЕШИТЬ ПРИЛОЖЕНИЕ**

Dental Bloom должен решать не только проблему нехватки знаний, но и проблему организации обучения.

### **Проблема №1. Не знает, с чего начать**

Решение:

На главном экране всегда есть один рекомендуемый урок.

Ученице не нужно самостоятельно выбирать из сотни тем.

### **Проблема №2. Сложно понимать немецкие учебные материалы**

Решение:

Каждая сложная тема объясняется сначала на русском, затем простым немецким языком.

### **Проблема №3. Сложно запоминать профессиональные термины**

Решение:

Интерактивные карточки, примеры, короткие тесты и интервальное повторение.

### **Проблема №4. Очень слабый английский**

Решение:

Отдельная программа English from Zero.

Начинать с букв, звуков, чтения простых слов и базовой лексики.

### **Проблема №5. Нет мотивации учиться каждый день**

Решение:

Короткие занятия, приятный интерфейс, небольшие достижения и отсутствие наказаний за пропуски.

### **Проблема №6. Сложно понять, что уже выучено**

Решение:

Отдельная система прогресса, которая показывает освоенные темы, сложные слова и результаты тестов.

# **4\. ЦЕЛИ И ПРИНЦИПЫ ПРОДУКТА**

## **4.1. Главные цели**

За первый месяц приложение должно помочь:

* сформировать привычку заниматься;  
* лучше понимать базовые темы ZFA;  
* запомнить первые профессиональные немецкие термины;  
* начать читать простые английские слова;  
* освоить базовую английскую лексику;  
* научиться отвечать на простые вопросы;  
* выявить слабые темы.

## **4.2. Время обучения**

Основной формат:

* стандартный урок: 10–15 минут;  
* короткий урок: 5 минут;  
* повторение: 3–7 минут;  
* дополнительное занятие: по желанию.

Не нужно заставлять ученицу проводить в приложении час.

Лучше 10 минут качественного обучения, чем 60 минут перегруженного материала.

## **4.3. Принципы**

1. Простота важнее количества функций.  
2. Обучение важнее геймификации.  
3. Понимание важнее механического запоминания.  
4. Повторение важнее постоянного добавления новых слов.  
5. Никаких наказаний за пропущенные дни.  
6. Ошибки — нормальная часть обучения.  
7. Каждый урок должен иметь конкретную цель.  
8. Учебный материал должен соответствовать уровню ученицы.  
9. Приложение должно быть удобным на смартфоне.  
10. Стоматологическая информация должна быть проверенной.

# **5\. УЧЕБНАЯ СИСТЕМА DENTAL BLOOM**

В приложении будет три основных направления обучения.

## **5.1. ZFA Schule**

Основное направление.

Здесь ученица изучает профессиональные темы:

* зубы и их строение;  
* кариес;  
* лечение кариеса;  
* стоматологические инструменты;  
* гигиена;  
* приём пациентов;  
* ассистирование стоматологу;  
* обработка медицинских инструментов;  
* документация;  
* лечение и профилактика;  
* профессиональные процедуры.

Темы необходимо добавлять постепенно, основываясь на реальной школьной программе.

## **5.2. Deutsch für ZFA**

Профессиональный немецкий язык.

Здесь ученица изучает:

* стоматологические термины;  
* артикли;  
* профессиональные глаголы;  
* простые предложения;  
* понимание инструкций;  
* формулировки школьных заданий;  
* ответы на вопросы преподавателя;  
* диалоги с пациентами.

## **5.3. English from Zero**

Отдельный курс английского языка.

Начинается практически с нуля.

Последовательность:

1. Alphabet.  
2. Letter names.  
3. Basic sounds.  
4. Reading simple words.  
5. Basic vocabulary.  
6. Everyday phrases.  
7. Body parts.  
8. Dental vocabulary.  
9. Simple patient communication.

Три направления должны быть связаны между собой.

Например, тема недели — зубные инструменты.

Ученица изучает:

* что такое Mundspiegel на русском;  
* как объяснить его простым немецким;  
* как называется dental mirror на английском;  
* как использовать слово в простом предложении.

Таким образом, одна тема помогает одновременно развивать профессиональные знания и два языка.

# **6\. НАПРАВЛЕНИЕ ZFA SCHULE**

Основной курс должен быть связан с реальными Lernfelder Ausbildung ZFA.

В Германии профессиональное обучение включает теоретическую подготовку и практику. Структура обучения опирается на официальные требования, но конкретная последовательность школьных тем может отличаться в зависимости от школы и региона.

Поэтому приоритет:

1. Реальные материалы ученицы.  
2. Задания преподавателя.  
3. Темы Berufsschule Rosenheim.  
4. Официальные учебные документы.  
5. Дополнительные проверенные источники.

Необходимо избегать создания универсальной программы, которая может не совпадать с тем, что сейчас проходит ученица.

## **Примеры будущих учебных тем**

* Patienten empfangen und begleiten.  
* Hygienemaßnahmen.  
* Medizinprodukte aufbereiten.  
* Kariestherapie.  
* Zahnmedizinische Instrumente.  
* Prophylaxe.  
* Patientenberatung.  
* Dokumentation.  
* Assistenz bei Behandlungen.

Начать необходимо с уже известной темы LF 4\.

# **7\. НАПРАВЛЕНИЕ DEUTSCH FÜR ZFA**

Немецкий язык должен изучаться через реальные профессиональные ситуации.

Не нужно создавать отдельный сложный курс грамматики.

Грамматика должна объясняться на примерах из ZFA.

## **Примеры тем**

### **Артикли**

* der Zahn;  
* die Karies;  
* die Füllung;  
* das Instrument.

### **Глаголы**

* prüfen — проверять;  
* behandeln — лечить;  
* entfernen — удалять;  
* einsetzen — устанавливать;  
* vorbereiten — подготавливать;  
* beraten — консультировать;  
* untersuchen — осматривать;  
* reinigen — очищать.

### **Простые предложения**

Der Zahnarzt untersucht den Zahn.

Стоматолог осматривает зуб.

Die ZFA bereitet die Instrumente vor.

Ассистент подготавливает инструменты.

Der Patient hat Schmerzen.

У пациента есть боль.

### **Понимание школьных заданий**

Учить ученицу понимать такие формулировки:

* Erklären Sie …  
* Beschreiben Sie …  
* Nennen Sie …  
* Vergleichen Sie …  
* Ergänzen Sie …  
* Kreuzen Sie an …  
* Begründen Sie …

Объяснять каждую формулировку на русском и давать короткий пример.

## **Уровень сложности**

Начальный уровень:

* короткие предложения;  
* простая грамматика;  
* небольшой словарный запас;  
* русский перевод.

Постепенно:

* больше немецкого;  
* меньше русского;  
* более длинные профессиональные предложения;  
* самостоятельные ответы.

Не переводить всё на русский навсегда. Цель — постепенно развивать понимание немецкого.

# **8\. НАПРАВЛЕНИЕ ENGLISH FROM ZERO**

Это отдельный важный модуль.

Необходимо учитывать, что ученица почти не знает английского и испытывает трудности с чтением.

Нельзя начинать обучение с длинных профессиональных предложений.

## **Этап 1\. Alphabet**

Изучение английского алфавита.

Для каждой буквы:

* большая буква;  
* маленькая буква;  
* название буквы;  
* аудио произношения;  
* пример слова;  
* упражнение на узнавание.

Пример:

A a

Название буквы: /eɪ/

Пример слова: apple.

Важно объяснить разницу между названием буквы и её звуком в слове.

## **Этап 2\. Sounds**

Постепенное знакомство со звуками.

Необходимо объяснять, что одна буква может произноситься по-разному.

## **Этап 3\. Reading**

Простые слова:

* cat;  
* pen;  
* map;  
* bed;  
* sun.

Ученица должна научиться узнавать слово и произносить его.

## **Этап 4\. Basic vocabulary**

Простые слова:

* hello;  
* goodbye;  
* yes;  
* no;  
* please;  
* thank you;  
* water;  
* hand;  
* head.

## **Этап 5\. Body parts**

* head;  
* mouth;  
* tooth;  
* teeth;  
* tongue;  
* hand;  
* eye;  
* nose.

## **Этап 6\. Dental English**

* dentist;  
* patient;  
* dental mirror;  
* tooth;  
* teeth;  
* filling;  
* pain;  
* mouth;  
* appointment.

## **Этап 7\. Patient communication**

Простые предложения:

* Hello\!  
* Please sit down.  
* Open your mouth.  
* Does it hurt?  
* Thank you.  
* Please wait.

Необходимо добавлять перевод на русский и немецкий.

## **Требования к английскому**

* Начинать с нуля.  
* Не перегружать грамматикой.  
* Использовать короткие задания.  
* Давать аудио, если оно доступно.  
* Не использовать русскую транскрипцию как единственный способ изучения произношения.  
* Не переходить к длинным предложениям, пока не освоено чтение простых слов.

* mesial;  
* distal;  
* labial;  
* bukkal;  
* okklusal;  
* Zahnsteinentfernung;  
* Mundschleimhautbehandlung;  
* Aphte;  
* Heil- und Kostenplan;  
* Präparation;  
* Abdruck;  
* Retraktionsfäden;  
* provisorische Krone;  
* Krone;

Что такое кариес?

### **Урок 2\. Der Zahn**

### **Урок 4\. Zahnmedizinische Instrumente**

Инструменты:

### **Урок 5\. Vitalitätsprüfung**

### **Урок 6\. Kofferdam**

Что такое Kofferdam и для чего он используется.

### **Урок 7\. Füllung**

Матрица и деревянные клинья.

Что означает HKP.

### **Урок 12\. Kronen**

Коронки, подготовка зубов и временные коронки.

### **Урок 13\. Behandlungsfall Nr. 8**

Разбор учебного клинического случая.

### **Урок 14\. Wiederholung**

Повторение и итоговый тест.

# **11\. СТРУКТУРА ОДНОГО УРОКА**

Это один из важнейших элементов приложения.

Каждый урок должен иметь понятную повторяющуюся структуру.

Ученица должна сразу понимать, что ей делать.

## **Пример: Was ist Karies?**

Продолжительность: 10–12 минут.

### **Этап 1\. Learn — 3 минуты**

Объяснение на русском:

Кариес — это заболевание, при котором повреждаются твёрдые ткани зуба.

Einfaches Deutsch:

Karies ist eine Erkrankung der Zähne.

Показать иллюстрацию зуба с кариесом, если есть проверенное изображение.

### **Этап 2\. Vocabulary — 3 минуты**

Карточки:

* der Zahn — зуб;  
* die Karies — кариес;  
* die Füllung — пломба;  
* der Patient — пациент;  
* die Behandlung — лечение.

### **Этап 3\. Practice — 3 минуты**

Короткие задания:

* выбрать правильный перевод;  
* соединить слово с определением;  
* выбрать правильный термин;  
* ответить на простой вопрос.

### **Этап 4\. Test — 2–3 минуты**

Три-пять вопросов.

После ответа показывать:

* правильно или неправильно;  
* правильный ответ;  
* короткое объяснение.

### **Этап 5\. Completion**

Экран завершения:

* урок пройден;  
* сколько правильных ответов;  
* какие слова выучены;  
* какие слова нужно повторить;  
* кнопка возврата на Home.

## **Правила уроков**

* Не использовать длинные абзацы.  
* Не показывать много новых слов за один раз.  
* Сложные термины объяснять отдельно.  
* Использовать понятные примеры.  
* Не делать задания слишком сложными.  
* Не показывать неправильный ответ без объяснения.

# **12\. СИСТЕМА ПОВТОРЕНИЯ**

В приложении обязательно должна быть система повторения.

Нельзя ограничиваться тем, что ученица один раз посмотрела карточку и перешла дальше.

Каждое слово или понятие должно возвращаться через определённое время.

## **Простой алгоритм**

Если ученица не помнит слово:

* повторить позже или на следующий день.

Если ответила правильно, но неуверенно:

* повторить через один день.

Если ответила правильно:

* повторить через три дня.

Если два раза подряд ответила правильно:

* повторить через семь дней.

Затем:

* через четырнадцать дней.

Не нужно реализовывать сложный алгоритм интервального повторения в первой версии.

Главное — чтобы приложение сохраняло карточки и возвращало их в нужный момент.

## **Кнопки карточки**

* Не помню.  
* Сложно.  
* Знаю.

На основании ответа обновлять дату следующего повторения.

# **13\. АДАПТИВНЫЙ УЧЕБНЫЙ ПЛАН**

В будущем Dental Bloom должен постепенно становиться персональным.

Приложение должно учитывать:

* какие темы ученица уже прошла;  
* какие темы вызывают ошибки;  
* какие слова она забывает;  
* какие уроки ещё не пройдены;  
* какие темы недавно проходили в школе;  
* сколько времени она хочет заниматься сегодня.

Не нужно сразу реализовывать сложный AI-алгоритм.

Для первой версии достаточно простого правила:

1. Если есть слова на повторение — предложить повторить их.  
2. Если есть незавершённый урок — предложить продолжить.  
3. Если повторение не требуется — предложить следующий урок.  
4. Если ученица устала — предложить короткий урок.

## **Кнопка «Сегодня я устала»**

На Home должна быть отдельная возможность:

**Heute bin ich müde.**

Она запускает короткий режим:

* один простой термин;  
* одно короткое объяснение;  
* три вопроса;  
* завершение за пять минут.

Не заставлять ученицу выполнять полноценную программу в тяжёлый день.

# **14\. ГЕЙМИФИКАЦИЯ — DENTAL GARDEN**

Идея: виртуальный сад, который постепенно развивается благодаря обучению.

За завершённые уроки ученица получает цветы или другие элементы сада.

Принципы:

* каждый завершённый урок даёт небольшой прогресс;  
* освоенные темы открывают новые растения;  
* можно собирать изображения стоматологических инструментов;  
* нет штрафов за пропущенные дни;  
* растения не умирают;  
* достижения не теряются;  
* ошибки не приводят к наказанию.

Важно:

**Dental Garden не должен быть важнее самого обучения.**

Полноценную механику сада не нужно делать в MVP.

В первой версии достаточно простого прогресс-бара.

# **18\. ТЕХНИЧЕСКИЙ СТЕК**

У пользователя уже есть опыт:

* PWA;  
* GitHub;  
* Supabase;  
* Cloudflare.

Поэтому не нужно без необходимости менять привычные инструменты.

### **Frontend**

React \+ Vite \+ TypeScript.

Почему:

* простой старт;  
* хорошая поддержка;  
* удобно разделять компоненты;  
* легко развивать приложение.

Tailwind CSS.

Использовать для создания адаптивного интерфейса.

### **Routing**

React Router — только если он действительно нужен для нескольких страниц.

### **Local database**

Dexie.js \+ IndexedDB.

Для хранения:

* прогресса;  
* завершённых уроков;  
* карточек;  
* повторений.

### **Hosting**

Cloudflare Pages.

### **Version control**

GitHub.

### **Backend — позже**

Supabase.

Для:

* авторизации;  
* резервного копирования;  
* синхронизации между устройствами.

### **PWA**

Service Worker и PWA plugin для Vite.

## **Главное архитектурное решение**

**Начинать с Local-first Architecture.**

Приложение должно работать без обязательной регистрации и без постоянного подключения к серверу.

Контент хранится в проекте.

Прогресс хранится локально.

Интернет нужен только для дополнительных функций, если они будут добавлены позднее.

Не строить сложную архитектуру.

**UI → Learning Logic → Local Database → Content**

### **UI**

Все страницы и компоненты интерфейса.

# **24\. SUPABASE И СИНХРОНИЗАЦИЯ**

Supabase не нужен для самого первого прототипа.

В будущем использовать для:

* авторизации;  
* резервного копирования;  
* синхронизации прогресса;  
* переноса данных между устройствами.

Не отправлять каждый клик на сервер.

Локальная база остаётся основной для быстрой работы приложения.

Если появится Supabase:

* использовать Row Level Security;  
* не публиковать service role key во frontend;  
* хранить секреты только в защищённом окружении;  
* не открывать доступ к чужим учебным данным.

# **25\. ВОЗМОЖНОСТИ AI**

AI может стать полезным дополнением, но не должен быть основой первой версии.

Сначала создать проверенный контент.

Позже AI можно использовать для:

2. Переформулирования текста на уровне A2.  
3. Создания дополнительных тренировочных вопросов.  
4. Генерации простых диалогов.  
5. Подбора упражнений по ошибкам.  
6. Помощи с пониманием немецких школьных заданий.

## **Медицинские ограничения**

AI не должен самостоятельно придумывать медицинские факты.

Все стоматологические объяснения должны опираться на проверенные материалы.

AI должен помогать объяснять уже проверенный материал, а не заменять медицинский источник.

## **Технические ограничения**

Если подключается API:

* ключ не должен находиться во frontend;  
* использовать Cloudflare Worker или другой серверный слой;  
* ограничить количество запросов;  
* предусмотреть ошибки API;  
* не отправлять персональные данные пациентов;  
* отправлять учебные данные только с понятным согласием пользователя.
